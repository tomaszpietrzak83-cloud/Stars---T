Implemented changes
- Reject route obstacles with disjoint expanded bounding boxes, retaining exact
  segment distance tests for overlapping boxes and boundary contact. Minefield
  radius is computed once per field examination.
- Cache corridor threats within each standalone return-fuel calculation; nested
  calculations reuse the enclosing route search cache. No results survive the
  enclosing search. Existing bounded cache and invalidation rules remain intact.
- Reuse speed safety decisions within one station calculation; hoist invariant
  speeds, distance and fleet classifications out of the return-fuel inner loops.
  Stop when a valid zero-fuel return is found: no nonnegative minimum can improve.
- Reuse route-search scratch slices. Each accepted node keeps its own arrival
  fuel slice, preventing aliasing between candidate routes.
- Filter owned colonies once per patrol target sort, calculate each deadline once,
  and avoid the duplicate colony scan in finding the defended colony. Stable ties,
  public-intel restrictions, priorities and mutation refresh between calls remain.
- Cache nearest-enemy distances only within each friendly-fleet sort; clear the
  cache before the next sort after patrol assignments/releases.
- Build occupied patrol targets once per assignSoloPatrol call, replacing the
  enemy-by-own-fleet repeated scan. Assignments change only at successful return.
  The measured intermediate profile attributed about 22 CPU seconds to that scan.
- Avoid JSON decoding for empty maintenance/logistics tags; stop incoming rebuild
  demand scanning after the existing yard resource budget has been exhausted.
  No ship, patrol, transport, safety, priority or fuel rule was changed.
