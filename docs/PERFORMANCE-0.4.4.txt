Route audit on the same year-2475 archive: approximately 86.5 seconds before threat classification indexing and 5.84 seconds after it, with matching outcomes. Harmless scout/cargo reports are classified once per orders phase; the index is discarded before physical universe changes.

Simulation stages with dependencies, discovery/allied intel updates and SQLite writes stay serial. Read-only scanner calculations and independent AI owners use bounded workers. Native owner-worker failures propagate to the parent transaction handler rather than killing the process from a child goroutine.

Validation: complete native core, AI, server, database and converter tests; updated synthetic AI battle recordings for the intentional new combat tactics; 72 selected frontend tests; Svelte check with zero errors/warnings; compiled isolated browser smoke with real API persistence. Production forecast gates compare all ship/base batch deadlines with native UI estimates.
