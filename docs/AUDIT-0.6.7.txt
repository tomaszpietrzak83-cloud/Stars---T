Version 0.6.7 — annual resources on the galaxy map

Request
- Add R beside Population. The largest resource-producing planet in the empire
  represents 100%; every other circle represents its fraction of that maximum.
  Use light sky blue.

Implementation
- Added Resources as a separate saved planet view, preserving the numeric values
  of every existing view and keyboard shortcut. R is immediately after Population
  in the toolbar and the narrow-screen menu; its active icon also identifies the
  collapsed menu. Responsive width accounting includes the sixth icon.
- The scale uses current owned planet specs: total resourcesPerYear before the
  production/research split, matching the empire annual-resource summary. A stale
  intel value or an enemy/ally planet cannot change the empire maximum.
- Filled circles use #87cefa. Circle AREA represents the fraction, so 500 versus
  a maximum of 1000 has half the area. The maximum radius is 21 pixels in the
  detailed map and 11 when zoomed out; uniform zoom scaling preserves the ratios.
- Zero-production and non-owned planets retain normal map markers. Zero maximum
  does not divide by zero. Existing names, fleet counts, selection and waypoint
  clearance account for the resources circle's extent.

  production excluded, stale report values replaced by current specs, changing
  the empire maximum and zero-production visibility.
- 21 Chrome component tests pass. Real canvas pixel sampling verifies the exact
  light-blue fill and proportional circle areas; toolbar tests verify R selection,
  adjacency to Population and no overflow across phone/tablet/desktop widths,
  with and without ally filters and a deletable waypoint.
- Svelte/TypeScript check: zero errors and warnings. Native Windows executable,
  WASM and compiled static UI rebuilt. Final isolated Chrome smoke on ports
  18097/18783 verifies R, actual blue map pixels, saved selection after reload,
  desktop and phone menu; fresh test database stays in year 2400. Embedded WASM
