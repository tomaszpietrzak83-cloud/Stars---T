Changes, with unchanged rules and tie breakers
1. Compute the convoy speed bound first. Without compatible gates, reject an
   impossible straight-line deadline before calculating return fuel. Compatible
   gates disable the geometric rejection. Keep a tiny conservative boundary slack.
2. In graph search, reject a strictly worse score lower bound before safety/fuel
   work. Edge fuel burn is nonnegative; equality still reaches the original
   time/HighestWarp tie breakers. No heuristic truncation or search-limit change.
3. Cache minefield intersection geometry per route search, independent of warp.
   Evaluate sweeping, safe warp, outward escape and detonation separately at each
   speed. Cache empty results, bound entries4096, restore enclosing caches on exit.
4. Stop mine-detour return searches when a valid required reserve reaches zero.
5. Give fuel-network route searches the same scoped threat/mine caches and test
   their existing time budget before expensive safety checks. Donor allocations,
   label dominance, expansion limit, visit order and fuel budgets are unchanged.
6. Within one dispersed-pack reassignment batch, reuse reconnaissance answers for
   immutable public reports. The local closure is discarded after the batch;
   later phases and other batches re-read reports. No Player-level persistent cache.
7. Cache only maintenance destination/stage/validity, keyed by the exact raw tag.
   Use the existing complete JSON decoder, so malformed nested orders still fail.
   Never expose mutable cached orders. Reuse yard rebuild priority in its source loop.
8. Avoid allocating/copying/sorting token slices for zero/one-design fleet fuel
   calculations; retain the exact mass/cargo/engine formula and mixed-fleet path.
