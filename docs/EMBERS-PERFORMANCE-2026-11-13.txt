Implemented performance changes
- Conservative spatial filtering of military arrival threats, preserving report
  order and the exact final geometry predicate. Civilian rules are unchanged.
- Per-search fuel-network edge safety/full-tank calculation reuse, with bounded
  storage. Fuel allocations, visited nodes, queue ordering, expansion limits and
  tie breakers remain unchanged.
- Remove discarded labels only from dominance comparisons; retain their heap
  entries and expansion accounting. Copy route histories only for accepted labels.
- Avoid colonization JSON decoding for unrelated roles; classify traffic once
  within immutable route/return calculations.
- Use the existing optimistic gate-aware travel bound to skip unwatched
  minelayer interceptions that already required arrival within one turn.
- Share exact leg-safety results between the return-dock searches of one unchanged
  fleet/report snapshot. The 65,536-entry maximum is a cache limit, not a search
  limit; a full cache still computes uncached answers normally.
- Reject strictly interior mined destinations before planning an impossible
  return. Keep sweeper exceptions, gate checks, starting-at-destination behavior
  and numerical boundary cases in their existing exact paths.

Confirmed bug and merge regression
Cleanup incorrectly skipped a nearby target because its mission rank was higher
than the main target. Diagnostics demonstrated funded, zero-loss, deadline-safe
interceptions. Removed that rejection; claims, reconnaissance, urgent defence,
fuel/return checks, damage threshold and rendezvous deadline still apply.
The old patrol-cycle test omitted the native post-movement/pre-battle merge
phases. It now executes them and still explicitly requires physical merging,
an actual enemy kill, and subsequent dispersal. It was NOT weakened to accept
separate fleets arriving together. Production already invokes these merge phases.

Remaining opportunities
Later profiling identifies tanker anchor scoring: it repeatedly classifies fleets
and decodes tanker jobs for each candidate position. An immutable scoring snapshot
per tanker can preserve summation order while avoiding that repetition. This is
a follow-up candidate, not part of the installed change.
Logistics/shipyard demand also repeatedly decodes logistics orders. Scope caches
to an immutable calculation or key them by exact tag contents; orders change
during the turn, so a stale whole-turn cache would be incorrect.
The timing is dominated by simulation, not disk writes or graphical rendering.
