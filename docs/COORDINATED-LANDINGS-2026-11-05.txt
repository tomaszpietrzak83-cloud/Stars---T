Coordinated automatic transport landings — implementation and acceptance

Requested behavior
Loaded transports physically gather one year's jump from a hostile colony,
with a scout and at least two patrol ships. Transports merge into a real fleet;
armies are not limited by an individual transport's hold. Reconnaissance checks
orbital threats, not whether the ground battle is risk-free. An incoming hostile
warship requires patrol protection already at the destination. A base suspends
the drop and requests a separately assessed patrol attack, followed by recon.

Implementation
cs/landingoperation.go stores the operation on its transport leader. Each member
has a leader reference; all loading, movement, fuel use, merging, battle and drops
use physical game objects and native rules. Phases: gather, scan, base, assault,
landed. Losing the target or disabling automation releases the operation.
Surviving escort tokens return to patrol duty after completion.

Empty available freighters start loading before a scout or escort is available.
The source keeps the configured population reserve. Sources at 95% population
capacity receive loading priority. Existing mineral, installation and ordinary
passenger cargo is not commandeered. Reservations prevent multiple transports
from counting the same population surplus. Newly available freighters reinforce
an incomplete army. Up to three new targets can start preparing per turn.
Existing armies receive reinforcements before another target can claim free
holds. Completed freighter rebuilds resume their role immediately, without
waiting for other shipyards; ships still needing maintenance are not released.

Old solo invade/invade-load jobs migrate to coordinated preparation, retaining
their actual cargo. Enemy population estimates determine provisions; report age
does not exponentially inflate the army. Ground defenses affect native losses,
but are not a scout veto. No remotely hidden enemy state is consulted; physical
scout contact transmits orbital reports before battle.

Transport safety
Crossing courses mid-year does not itself cause a native battle. Freighters now
check the actual/predicted arrival point instead. Battles can still occur in
deep space when opposing fleets finish at the same position. Mines, fuel and
hostile bases remain relevant. Reconnaissance and coordinated assault routes
have explicit orbital checks.
